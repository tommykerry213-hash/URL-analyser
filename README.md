# URL-analyser
A lightweight Python tool to detect suspicious or malicious URLs.  
Features:
- Domain reputation check (OpenPhish, Phishunt feeds)
- SSL/TLS certificate validation
- Shortener expansion (bit.ly, etc.)
- Heuristic analysis (IP in URL, excessive subdomains, hyphenated domains)
- WHOIS lookup for domain age
- Risk scoring (0–100)
